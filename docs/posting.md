# docs/posting.md

## 1. 게시글 구조

### 게시판 (Board)

| 게시판 | 설명 |
|--------|------|
| CREDIT | 신용 — 아이템-현금 거래 |
| ED | ED — ED-현금 거래 |
| GENERAL | 일반 — 아이템-ED 거래 |
| OTHER | 기타 |

### 거래 종류 (Category)

| 값 | 표시 | 허용 게시판 |
|----|------|------------|
| SELL | 팝니다 | 전체 |
| BUY | 삽니다 | 전체 |
| TRADE | 교환 | GENERAL만 |

### 거래 상태 (Status)

| 값 | 표시 |
|----|------|
| OPEN | 거래 가능 |
| RESERVED | 예약 |
| COMPLETED | 거래 완료 |

---

## 2. 게시판 표시 우선순위

게시판 목록에서 게시글은 3단계로 구분된다:

```
1. ★ 프리미엄  (isPremium=true, premiumUntil > now)
2. 일반         (USER/ADMIN 작성, 프리미엄 아님)
3. 임시 게시글  (TEMP 작성, 24시간 이내)
```

임시 게시글은 별도 섹션으로 목록 하단에 표시되며, 어두운 배경으로 시각적으로 구분된다.

---

## 3. TEMP 유저 게시글 정책

### 허용 범위

- 게시글 작성 가능 (1일 1개)
- 작성 후 24시간이 지나면 목록 및 상세 페이지에서 자동 숨김 (물리적 삭제 아님)

### 제한 이유

- 미인증 계정의 스팸/어뷰징 방지
- 인증(USER 전환) 유인 제공

### 구현 상세

| 동작 | 구현 위치 |
|------|----------|
| 1일 1개 제한 | `createPost` — 최근 24시간 내 게시글 수 조회 |
| 목록 분리 표시 | `posts/page.tsx` — `author: { role: TEMP }` + `createdAt > 24h ago` 별도 쿼리 |
| 상세 접근 차단 | `posts/[id]/page.tsx` — TEMP 작성자 + 24시간 초과 시 `notFound()` |

## 4. 게시글 작성 필드

### 공통 필드

| 필드 | 설명 | 제약 |
|------|------|------|
| title | 아이템명/가격/수량 | 최대 256 게임길이 (한글=2) |
| board | 게시판 | CREDIT / ED / GENERAL / OTHER |
| category | 거래 종류 | 게시판별 허용 값 다름 |
| status | 거래 상태 | OPEN / RESERVED / COMPLETED |
| negotiable | 흥정 여부 | boolean |
| tradeMethod | 거래방식 | 게시판별 다름 |
| content | 기타 사항 | 선택, 최대 256 게임길이 |

### GENERAL 전용 필드

| 필드 | 설명 | 규칙 |
|------|------|------|
| characterName | 거래자 캐릭터명 | 한글/영문/숫자, 최대 게임길이 12 |

캐릭터명 형식: `닉네임` 또는 `닉네임@S` / `닉네임@G`

---

## 5. 프리미엄 게시글

- `isPremium: true` + `premiumUntil` 설정 시 목록 최상단 노출
- 만료 임박 순으로 정렬 (premiumUntil asc)
- 기본 10건 표시, "더보기"로 전체 확인 가능
- 현재 관리자가 직접 설정 (자동 결제 미구현)
