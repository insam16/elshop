# docs/posting.md

## 1. 게시글 구조

### 게시판 (Board)

| 게시판 | 설명 |
|--------|------|
| CREDIT | 신용 — 아이템-현금 거래 |
| ED | ED — ED-현금 거래 |
| GENERAL | 일반 — 아이템-ED 거래 |
| OTHER | 기타 |

### 거래 종류 (Category)

| 값 | 표시 | 허용 게시판 |
|----|------|------------|
| SELL | 팝니다 | 전체 |
| BUY | 삽니다 | 전체 |
| TRADE | 교환 | GENERAL만 |

### 거래 상태 (Status)

| 값 | 표시 |
|----|------|
| ACTIVE | 거래 가능 |
| RESERVED | 예약 |
| COMPLETED | 거래 완료 |
| EXPIRED | 만료됨 |

---

## 2. 게시판 표시 우선순위

게시판 목록에서 게시글은 2단계로 구분된다:

```
1. ★ 프리미엄  (isPremium=true, premiumUntil > now)
2. 일반         (모든 role 작성, 프리미엄 아님)
```

프리미엄 게시글은 연한 보라색 배경으로 표시된다.
일반 중에서, USER와 TEMP 작성 게시글은 기본색 배경으로, 구분하여 표시되지 않는다.
거래완료와 만료된 게시글은 연한 회색 배경 + 다크모드에서 투명도 낮게 표시된다.

## 3. TEMP 유저 게시글/댓글 정책

### 허용 범위

- 게시글 작성 가능 (1일 1개)
- 댓글 작성 가능 (1일 3개)
- 작성된 게시글은 삭제 전까지 목록에 계속 표시됨

### 제한 이유

- 미인증 계정의 스팸/어뷰징 방지
- 인증(USER 전환) 유인 제공

### 구현 상세

| 동작 | 구현 위치 |
|------|----------|
| 1일 1개 제한 | `createPost` — 최근 24시간 내 게시글 수 조회 |

## 4. 게시글 작성 필드

### 공통 필드

| 필드 | 설명 | 제약 |
|------|------|------|
| title | 아이템명/가격/수량 | 최대 256 게임길이 (한글=2) |
| board | 게시판 | CREDIT / ED / GENERAL / OTHER |
| category | 거래 종류 | 게시판별 허용 값 다름 |
| status | 거래 상태 | ACTIVE / RESERVED / COMPLETED |
| negotiable | 흥정 여부 | boolean |
| tradeMethod | 거래방식 | 게시판별 다름 (아래 표 참고) |
| contact | 판매자 연락처 | 필수, `https://open.kakao.com/` 시작, 최대 200자 |
| characterName | 거래자 캐릭터명 | 선택, 전 게시판, 최대 게임길이 12 |
| content | 기타 사항 | 선택, 최대 256 게임길이 |

캐릭터명 형식: `닉네임` 또는 `닉네임@S` / `닉네임@G`

### 게시판별 거래방식 (tradeMethod)

| 게시판 | 선택 가능한 거래방식 |
|--------|-------------------|
| CREDIT | 아이템 확인 - 입금 - 거래 / 길드 가입 - 입금 - 거래 - 길드 탈퇴 / 기타 |
| ED | ED 확인 - 입금 - 거래 / 우편 / 게시판 / 기타 |
| GENERAL | 개인거래 / 게시판 / 기타 |
| OTHER | 입금 - 길드 마스터 위임 / 화면 공유로 닉네임 확인 - 입금 - 닉네임 삭제 - 닉네임 취득 / 기타 |

## 5. 프리미엄 게시글

- `isPremium: true` + `premiumUntil` 설정 시 목록 최상단 노출
- 만료 임박 순으로 정렬 (premiumUntil asc)
- 기본 10건 표시, "더보기"로 전체 확인 가능
- 현재 관리자가 직접 설정 (자동 결제 미구현)
