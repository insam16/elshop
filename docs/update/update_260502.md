# 업데이트 내역 (2026.05.02)

## 1. 연락하기 시스템 (핵심 기능)

게시글에 카카오톡 오픈채팅 연락처를 등록하고, 구매자가 1회 열람 후 자동 삭제되는 연락처 공개 흐름을 구현했습니다.

### 흐름 요약

- **판매자**: 게시글 작성 시 카카오톡 오픈채팅 링크를 연락처로 등록
- **구매자(USER)**: "지금 연락하기" 버튼 클릭 → 판매자 연락처 1회 팝업 표시 → 게시글이 RESERVED 상태로 전환, 연락처 자동 삭제
- **구매자(TEMP)**: 연락처를 직접 남기는 방식으로 판매자에게 연락 요청
- **판매자**: 댓글의 "지금 연락하기" 버튼으로 구매자 연락처 확인 후 RESERVED 전환
- 거래완료 시 게시글·댓글의 모든 연락처 일괄 삭제

### 변경 파일

- `src/app/posts/_components/PostForm.tsx` — 연락처 입력 필드 추가
- `src/app/posts/[id]/_components/ContactSection.tsx` — 구매자 연락 섹션 컴포넌트 (신규)
- `src/app/posts/[id]/_components/CompletePostButton.tsx` — 거래완료 버튼 컴포넌트 (신규)
- `src/app/posts/[id]/_components/Comments.tsx` — 판매자용 구매자 연락처 확인, 거래완료 흐름 추가
- `src/lib/actions/post.ts` — `contactPost`, `leaveContact`, `completePost` 액션 추가
- `src/lib/actions/comment.ts` — `contactComment` 액션 추가
- `src/lib/validators/post.ts` — `contact` 필드 검증 추가
- `prisma/schema.prisma` — `Post.contact`, `Post.expiresAt`, `Comment.contact` 필드 추가

## 2. 게시글 자동 만료 (expiresAt + cron)

- 게시글 작성 시 `expiresAt = 생성시각 + 7일` 자동 설정
- `src/app/api/cron/expire-posts/route.ts` (신규): `expiresAt`이 지난 게시글을 주기적으로 처리
  - ACTIVE → EXPIRED (연락처 삭제)
  - RESERVED → COMPLETED (연락처 삭제)

---

## 3. PostStatus 변경

`OPEN` → `ACTIVE`로 이름 변경, `EXPIRED` 상태 추가

| 상태 | 의미 |
|---|---|
| ACTIVE | 거래 가능 |
| RESERVED | 예약 |
| COMPLETED | 거래 완료 |
| EXPIRED | 만료됨 |

- 완료/만료 상태에서는 수정·댓글 작성 불가
- 관리자 계정은 게시글 작성 불가
