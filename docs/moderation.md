# 신고 및 제재 (Moderation)

> 관리자 패널 UI 및 처리 흐름은 [admin.md](./admin.md) 참조.

---

## 1. 개요

플랫폼은 거래를 중개하지 않으므로, 분쟁 조정이 아닌 사기/허위정보/부적절 콘텐츠 차단에 집중한다.  
모든 신고는 `reports` (게시글) / `comment_reports` (댓글) 테이블에 기록되며, 관리자가 수동으로 검토·처리한다.

---

## 2. 게시글 신고 (`reports`)

### 신고 접수

- 경로: 게시글 상세 페이지 → 신고 버튼 → 모달
- 로그인 필요 (역할 무관)
- 본인 게시글 신고 불가
- 동일 게시글에 중복 신고 불가 (`reporterId + postId` unique 제약)

### 신고 사유

| 코드 | 표시 |
|---|---|
| `FRAUD` | 사기 |
| `FALSE_INFO` | 허위 정보 |
| `INAPPROPRIATE` | 부적절한 내용 |
| `IMPERSONATION` | 타인 사칭 |
| `OTHER` | 기타 |

### 상세 설명

- 선택 입력, 최대 500자

### 신고 상태

| 코드 | 표시 | 색상 |
|---|---|---|
| `PENDING` | 대기중 | 노란색 |
| `REVIEWING` | 검토중 | 파란색 |
| `RESOLVED` | 처리완료 | 초록색 |
| `REJECTED` | 반려 | 회색 |

---

## 3. 댓글 신고 (`comment_reports`)

게시글 신고와 동일한 구조. 게시글 상세 페이지에서 댓글/답글 단위로 신고 가능.

- 본인 댓글 신고 불가
- 동일 댓글에 중복 신고 불가 (`reporterId + commentId` unique 제약)
- 신고 사유/상태는 게시글 신고와 동일

---

## 4. 작성자 삭제 요청

직접 게시글/댓글을 삭제할 수 없는 대신, 작성자가 삭제 요청을 접수할 수 있다.  
내부적으로 `reports` / `comment_reports` 테이블에 `reason = OTHER`, `detail = "[작성자 삭제 요청] ..."` 형태로 저장된다.

### 게시글 삭제 요청 (`requestPostDeletion`)

- 본인 게시글만 가능
- 동일 게시글에 1번만 가능 (중복 시 에러)
- 사유 선택 입력 (최대 500자)

### 댓글 삭제 요청 (`requestCommentDeletion`)

- 본인 댓글만 가능
- 동일 댓글에 1번만 가능
- 사유 선택 입력 (최대 500자)

## 5. 제재 (Ban)

### 제재 유형

| 유형 | `bannedUntil` 값 | 동작 |
|---|---|---|
| 기간 제한 | 미래 날짜 | 해당 날짜까지 이용 제한 |
| 영구 차단 | `9999-12-31` | 영구 이용 불가 |

### 제재 적용 범위

제재 중 계정은 다음 기능을 사용할 수 없다:

- 게시글 작성
- 연락하기 (판매자 연락처 조회)
- 연락처 남기기

제재 중에도 로그인 자체는 가능하며, 각 기능 실행 시 제재 메시지가 표시된다.

### 제재 만료

기간 제한 제재는 `bannedUntil` 이후 해당 기능 실행 시 자동으로 해제된다 (`checkAndExpireBan`).  
`bannedUntil <= now` 이면 DB에서 `isBanned = false`, `bannedUntil = null`로 업데이트한다.

### ADMIN 계정 보호

`role = ADMIN`인 계정은 제재할 수 없다.

---

## 6. 재가입 차단 (Cooldown)

탈퇴 후 `RetainedUser.retainUntil` 기간 내에는 동일 네이버 계정으로 재가입이 차단된다.  
로그인 시 `signIn` 콜백에서 `hashedNaverId`로 조회하며, 차단된 경우 `/login?error=AccessDenied`로 redirect된다.

보관 기간 기준:

| 조건 | 보관 기간 |
|---|---|
| 처리 완료된 신고(`RESOLVED`) 없음 | 1년 |
| `RESOLVED` 신고 1건 이상 | 3년 |

---

## 7. 콘텐츠 제한 (Rate Limiting)

관리자 제재와 별개로, `TEMP` 역할 계정에 대한 사용량 제한이 적용된다.

| 행위 | 제한 |
|---|---|
| 게시글 작성 | 24시간에 1개 |
| 댓글/연락처 남기기 | 24시간에 3개 |

서버 액션에서 직접 카운트 조회로 검증하며 별도 토큰/큐 없이 동작한다.
